### 3.1 Scholarships (CODE COMPLETE; BROWSER ACCEPTANCE PENDING SERVER)

**New Prisma models (additive, schema.prisma):**
- `Scholarship` — fields: slug (unique), name, provider, providerType, country, destinationCountries, educationLevels, eligibleNationalities, courseCategories, summary, coverage, amountSummary (nullable → "Information not available"), eligibilitySummary, applicationRoute, applicationUrl (nullable), applicationUrlVerified, deadlineDisplay (nullable), deadlineVerified, documentsRequired, verificationState, sourceName, sourceUrl, isActive, createdAt, updatedAt. Indexes on isActive/country/providerType/verificationState.
- `StudentApplication` — fields: studentId (User relation), institutionType (UNIVERSITY|INDIAN_INSTITUTION), institutionId, programName, status (ENUM: EXPLORING→WITHDRAWN), notes, createdAt, updatedAt. Unique on [studentId, institutionType, institutionId, programName].

**Seed script** (`scripts/seed-scholarships.mjs`): 11 curated scholarships with real official domains:
- AICTE Pragati/Saksham (India, GOVERNMENT)
- Central Sector Scheme / Post-Matric OBC / NMMS (India, NSP gateway scholarships.gov.in)
- Chevening, Commonwealth, DAAD, Erasmus Mundus, Fulbright (INTERNATIONAL_ORGANIZATION, GLOBAL destination)
- All amounts and deadlines intentionally null → UI displays "Information not available"
- Verification states: PARTIALLY_VERIFIED / DATA_REQUIRED (honest; never upgraded to VERIFIED)
- Every row carries a verified official source URL

**Feature gate:** `scholarshipHub` in `StudentFeatureAccess`; `/scholarships` redirects to `/dashboard` when off.

**Page** (`src/app/(student)/scholarships/page.tsx`): server component with auth + flag gate, passes list + saved IDs to client explorer.

**Client explorer** (`src/app/(student)/scholarships/scholarship-explorer.tsx`): search input + education-level filter + country filter + cards with verification badge, summary, coverage icons, "View details" link, save/unsave via shortlist API.

**API routes:**
- `GET /api/student/scholarships` — list active scholarships, optional `?q=&level=&country=` filters
- `GET /api/student/scholarships/[slug]` — detail + saved flag

**Shortlist integration:** `SCHOLARSHIP` added to `ShortlistItemType`; enrichment in shortlist API routes (`/api/student/shortlist` and `[type]/[itemId]`) resolves scholarship name → `/scholarships/[slug]`; toggle save/remove.

**Honesty:** `assessScholarshipFit` pure function produces status `POTENTIAL_MATCH / REVIEW_ELIGIBILITY / MAY_APPLY / NOT_SURE` with never-a-guarantee disclaimer. Amounts/deadlines never fabricated; null → "Information not available".
